# Clear Sky native physics comparison, 2026-10-01

Local followup to [issue #2139](https://github.com/OpenXRay/xray-16/issues/2139).
These captures measure the starting base in the supplied Clear Sky installation;
they are separate from the Call of Pripyat results.

## Results

Three captures per backend, alternating forward/reverse order. Values below
are medians of the three per-run means for complete physics-step wall time.

| Backend | Idle ms/step | Driven ragdolls ms/step |
| --- | ---: | ---: |
| Jolt CDB + ODE | 0.029981 | 0.853384 |
| Previous native, one worker | 0.745991 | 1.113842 |
| New native, one worker | 0.715952 | 1.097906 |

The local optimization lowers the idle median by 4.0%. Per-run idle ranges
are 0.733-0.748 ms before and 0.706-0.730 ms after. Native preparation falls
from 0.214 to 0.175 ms (18.1%). The ragdoll median falls by 1.4%, but ranges
overlap almost completely: 1.078-1.128 vs 1.079-1.131 ms. This does not
establish a repeatable ragdoll gain. Ragdoll preparation remains expensive:
0.503 ms before and 0.489 ms after.

Native is still 23.9 times the ODE idle step cost and 1.29 times its driven
ragdoll cost in this fixture. Frame-interval p95 medians are 2.070/2.917 ms
for ODE idle/ragdolls, 3.328/3.750 ms for previous native, and 3.313/3.748 ms
for new native. These include game/render work and are machine-specific.

Static-query origins, counts, hits and range sums match across all nine runs.
Median microseconds per query:

| Query | Jolt CDB + ODE | Previous native | New native |
| --- | ---: | ---: | ---: |
| Nearest ray | 1.182 | 1.300 | 1.231 |
| Any ray | 0.493 | 0.755 | 0.704 |
| Full box | 19.729 | 6.713 | 6.593 |

The new rays are 5.3%/6.7% faster than previous native. Full-box run ranges
overlap, so its 1.8% median difference is not a demonstrated gain from these
changes. Against the parent CDB, new native still loses the ray batches but
the shared-mesh full-box implementation is about 3.0 times faster here.
This contrasts with CoP's small full-box batch and is specific to the query
location and geometry in this fixture.

Reported static-model memory is 123,199,880 bytes for the parent vs
106,531,676 for either native build (13.5% lower). Median observed peak
working sets are 1,134 MiB ODE, 1,511 MiB previous native and 1,422 MiB new
native. Peaks include loading and are not a measurement of physics alone;
the smaller static-model counter does not establish smaller whole-game memory.

## Validation and assessment

All nine final captures have zero main/reload exit codes, twelve passing
ragdoll reload checks, and no fatal/script/benchmark failures or contact
profile output. All six native captures pass all 35 loaded-game checks.
One separate native pilot also passes these checks and reloads. Initial setup
launches failed on the old Lua profiler/escape behavior and the incompatible
CoP `xr_logic`; these were corrected before the pilot and timed comparison.
The previously documented shutdown exception was not observed in this set;
it remains unresolved and is not claimed fixed.

The complete native migration still does not substantiate issue #2139's
in-game speedup premise in this second game. Improvements to dry contact
preparation and rays carry over, while the port's idle cost remains much
larger than ODE's. Native logs show numerous existing corpse shells with all
eleven elements active during idle. Per-step body counters are approximately
163 native vs 3 ODE, but native includes virtual characters and ODE counts
active-island bodies, so they cannot quantify an equivalent workload ratio.
Auditing corpse sleeping/wake causes and the remaining contact prepass is a
next performance investigation; these observations do not prove their cause.

This is a starting-base fixture with one native worker, not a Clear Sky
campaign, multiplayer, vehicle or worker-scaling validation. No recommendation
to ship the migration follows from these timings.

The template, shared scratch cache, pilot and final captures add approximately
127 MiB in total; game archives, runtime binaries and PDBs are not copied.
C: has about 24.76 GiB free after the comparison. Older diagnostic artifacts
remain as described in NativePerformance.md; no blocked cleanup is claimed.
